# Brag Plan: OmGold ERP — Video 01/09 · Software ki Pehchaan

> Series "OmGold ERP — poori series" ka ek episode (9 videos, Hinglish). Poori series ka index: `../README.md`.

## What is this app?
OmGold ERP jewellery dukaan ka poora software hai — GST billing, tag-wala stock, gold loan (girvi), udhaar, schemes aur double-entry bahi-khata ek hi jagah, web + desktop + mobile par.

## The angle
Naya user software khol kar ghabraye nahi — pehle do minute mein dikha do ki ye kya hai aur kahan kya milta hai. Login → left menu ke 3 hisse → top bar → Home screen. Koi feature list nahi; asli screen par ungli rakh kar.
