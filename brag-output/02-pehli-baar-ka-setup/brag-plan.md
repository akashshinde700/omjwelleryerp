# Brag Plan: OmGold ERP — Video 02/09 · Pehli Baar ka Setup

> Series "OmGold ERP — poori series" ka ek episode (9 videos, Hinglish). Poori series ka index: `../README.md`.

## What is this app?
OmGold ERP jewellery dukaan ka poora software hai — GST billing, tag-wala stock, gold loan (girvi), udhaar, schemes aur double-entry bahi-khata ek hi jagah, web + desktop + mobile par.

## The angle
Software tabhi sahi chalta hai jab pehle din ka setup ek tay order mein ho: firm + GST → aaj ka rate → staff → customers. Har step asli screen par, usi order mein jisme dukaan-maalik ko karna hai.

## Hook (first 2-3 seconds)
Title card: peeche bada "02", saamne "Pehli Baar ka Setup". Narrator pehli hi line mein bata deta hai ki is video mein kya milega:
"पहला बिल बनाने से पहले चार चीज़ें चाहिए — फ़र्म की डिटेल, आज का रेट, कस्टमर और स्टॉक।"

## Key moments (the middle)
- **Is order mein setup kijiye** — Firm + GST → Settings → Daily Rates → Customers → Add Stock → Barcode / HUID → Pehla bill
- **Setup › Firms** — Setup → Firms → "Firm details / Edit"
- **Setup › Firms › Firm setup** — Firm Name · GSTIN · PAN · Address · State sahi = sahi GST (IGST ya CGST+SGST) · CGST 1.5% + SGST 1.5% = 3%
- **Setup › Settings › Daily Rates** — Setup → Settings → Daily Rates · 24K likhiye → 22K, 18K auto → Save all new rates · Roz subah sabse pehle rate bhariye

- **Customers › Customer account** — Naam par click → Outstanding · Gold · Loyalty · Yahin se New Sale · New Loan · Udhaar
